# Как работать с агентом — для тех, кто не пишет код

Код за вас пишет **Claude Code**. Ваша работа — поставить задачу, следить, что получается, и
решать. Git, ветки, worktree, слияния и проверки делает агент. Руками вы запускаете только то, что
написано ниже.

---

## 1. Установка (один раз, ~15 минут)

1. **Git** — <https://git-scm.com> (Windows: `winget install Git.Git`). При установке всё по
   умолчанию.
2. **Node.js LTS** — <https://nodejs.org> (Windows: `winget install OpenJS.NodeJS.LTS`).
3. **pnpm** — в новом окне терминала: `npm install -g pnpm@10`.
4. **Claude Code** — по инструкции на <https://docs.claude.com/en/docs/claude-code> (или
   `npm install -g @anthropic-ai/claude-code`). Нужен вход в аккаунт Claude — **у каждого свой**.
5. **Аккаунт GitHub** и принятое приглашение в репозиторий (придёт на почту).

Проверка в терминале — все четыре команды печатают версию:

```bash
git --version
node -v
pnpm -v
claude --version
```

## 2. Подготовка проекта (один раз)

```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>
git config user.name "Имя Фамилия"
git config user.email "почта-от-вашего-GitHub"
pnpm install
cp .env.example .env          # PowerShell: Copy-Item .env.example .env
```

Ключ OpenAI Саян передаст лично. Откройте `.env` в блокноте и впишите:

```
LLM_PROVIDER=responses
LLM_API_KEY=<ключ>
```

**Ключ никуда не пересылайте и не вставляйте в чат с агентом.** Без ключа всё тоже работает
(`LLM_PROVIDER=mock`): вместо модели запросы разбирает сценарный агент, а инструменты, данные и
карта — настоящие; поиск при этом лексический, без эмбеддингов.

При первом `git push` (его сделает агент) Git откроет браузер для входа в GitHub — войдите.

## 3. Запуск агента

В терминале, в папке репозитория:

```bash
claude
```

Вставьте **промпт своей дорожки** из `docs/plan.md`, раздел «Промпты — один на компьютер». Всё.
Дальше агент сам читает документы, делит работу и начинает.

## 4. Пять фраз, которых достаточно

| Когда | Что написать агенту |
| --- | --- |
| Каждые 30 минут и к каждой контрольной точке | **«Синхронизируй»** — он подтянет чужие изменения, проверит и отправит ваши |
| Хотите понять, что происходит | **«Что сделано и как это проверить?»** |
| Что-то упало или выглядит не так | **«Вот ошибка:»** и вставить текст ошибки или описать, что видите |
| Агент остановился и ждёт | **«Продолжай»** |
| Агент делает не то | Нажать **Esc**, затем написать, что не так |

Чтобы посмотреть приложение: **«Запусти приложение»** — и откройте <http://localhost:3000>.

## 5. Когда агент спрашивает разрешение

Claude Code спрашивает перед командами. **Разрешайте** команды `pnpm …`, `git …` и правку файлов
внутри папки проекта. **Не разрешайте и спросите Саяна**, если агент хочет:

- `git push --force` или удалить ветку на GitHub;
- удалить что-то вне папки проекта;
- вывести, отправить или записать в файл ключ из `.env`.

## 6. Если что-то пошло не так

| Что видите | Что делать |
| --- | --- |
| Агент пишет про конфликт | «Реши конфликт по правилам AGENTS.md» — в чужих файлах он берёт их версию |
| `GATE RED` или красные тесты | «Почини, чтобы pnpm check был зелёным» |
| Агент долго молчит | Подождать пару минут; потом Esc и «Продолжай» |
| Нужен файл чужой дорожки | Агент сам запишет просьбу в раздел «Запросы» в `docs/plan.md`. Скажите об этом в общий чат |
| Всё сломалось и непонятно почему | Не чините руками. Напишите Саяну и пришлите последние сообщения агента |
| Закончились лимиты Claude | Сообщить Саяну; продолжить в Codex, вставив тот же промпт |

## 7. Расписание

Контрольные точки — в `docs/plan.md`. Главные:

- **14:30** — у каждого первая часть запушена (схема, сигнатуры, пример данных).
- **21:30** — код заморожен, только исправления.
- **22:30** — видео записано, PDF готовы.
- **23:30** — форма отправлена.

Синхронизируйтесь **минимум каждые 30 минут**: чем дольше ждёте, тем больнее конфликт.
