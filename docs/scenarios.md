## Область кросс-платформенной проверки

Фактически запускалась **macOS ARM64, Node.js 24, Python 3.14**. Windows/Linux
не запускались на отдельных машинах; это ограничение проверки, а не подтверждённая поддержка.
Для Windows проверены передача пути с пробелами без shell и принудительные
`PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`: новый тест сначала воспроизвёл отсутствие настроек,
затем прошёл после исправления. README содержит команды через `Scripts/python.exe`,
поскольку `python3` может отсутствовать в Windows даже после активации venv.
Веса модели скачиваются при подготовке; автономные запросы используют только кэш.
Лексический режим и отказ Python испытаны без ключей и без сетевого провайдера.

1091 вместо прежних 1089 подтверждается исходными JSON: расширенный сбор добавил
квартал ЭКСПО-2017 и Alem.ai. Вручную уменьшать выборку или возвращать старые доли нельзя.

## 1. Экспо: необычное на 1–2 часа

и нынешний Alem.ai `way/454857501` являются отдельными записями.
Основной демонстрационный диалог требует дополнительного шага уточнения.

**Уточнённый вход:** «Я у Нур Алем, хочу посмотреть музей или необычное место на 1–2 часа пешком.»

## Прозрачность, экран и приватность

Название, координаты, категория и часы берутся из OSM; у рекомендации есть ссылка.
Описание Wikidata помечается отдельно. Популярность sitelinks не является отзывами.
Действия и время обозначены как сгенерированные идеи/оценки. Ни векторы, ни текст
модели не подтверждают цены, мероприятия, удобства или открытые двери.

В интегрированном коде есть карта MapLibre/OpenFreeMap с атрибуцией OSM, карточки,
приблизительная линия маршрута и геолокация по кнопке. Текст и экран используют
серверный выбор ID, данные проходят общую схему. Команда зафиксировала браузерные
проверки в плане и решениях. CLI-матрица и HTTP-проверка не заменяют новую
браузерную проверку локальной модели.

Браузер запрашивает согласие и округляет координаты до трёх знаков; сервер округляет повторно.
При отзыве координаты удаляются из последующих запросов и эха истории ответов.
Точность порядка 100 м не гарантирует анонимность. Текст автоматически не обезличивается.
История и координаты не сохраняются и не логируются приложением, базы данных нет;
инфраструктурные журналы проверяются отдельно при развёртывании.
Локальная модель получает текст через stdin; запросы не пишутся в кэш весов.
Живой провайдер получает переданные ему сообщения и координаты.
