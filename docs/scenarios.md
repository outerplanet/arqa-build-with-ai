# Тестовые сценарии и ограничения

**Прогулки по Астане** — RAG-помощник, который подбирает 1–3 места рядом с пользователем.
Build with AI 2026, секция AI for Smart City, кейс НИЦ Smart City.

| | |
| --- | --- |
| Дата прогона | 19 октября 2026, 19:08–19:13 по Астане (UTC+5), реальные серверные часы |
| Код продукта | коммит `2fd5700` (ветка `main`); от него собран и запущен `pnpm build` + `pnpm start` |
| Данные | 1250 мест в `data/poi.json`, собраны скриптом `pnpm collect` из OpenStreetMap и Wikidata 19.10.2026 (снимок OSM 13:20 UTC); фото Wikimedia Commons — у 15 мест |
| Поиск | эмбеддинги OpenAI `text-embedding-3-small`, 256 измерений, предрасчитаны для всех мест; без ключа и в режиме `mock` — лексический поиск |
| Модель агента | `gpt-6-luna` через OpenAI Responses API (режим `live`) |
| Сырые ответы | `docs/presentation-http-probes.json` — полный JSON каждого запроса и вызовов инструментов |

Каждый сценарий отправлен настоящим HTTP-запросом в `POST /api/chat` дважды: сервер с
`LLM_PROVIDER=mock` (без сети и ключа, инструменты вызываются по сценарию) и сервер с
`LLM_PROVIDER=responses` (инструменты выбирает модель). Текст ответа в обоих режимах собирает код
из результатов инструментов, поэтому модель не может дописать факты о месте.

В интерфейсе тот же ответ показан карточками на карте. У 15 мест в карточке есть фото из
Wikimedia Commons с автором и лицензией (в этом прогоне — у Байтерека и Ботанического сада).
Панель активности показывает каждый вызов инструмента с кратким итогом: какая локация найдена,
сколько мест подошло, сколько длится маршрут.

**Время ответа live:** медиана около 16 с, от 8 с (уточнение локации) до 26 с (Mega Silk Way).
Mock отвечает за 16–330 мс, маршрут — 3 с (расчёт пешего пути).

## Критерии приёмки из кейса

Каждый ответ проверялся по требованиям организаторов (`docs/case.md`) и автоматически скриптом
`pnpm scenarios`:

1. **1–3 конкретных места**, каждое с расстоянием и минутами пешком.
2. **Почему** — краткое объяснение для каждого места.
3. **Время на посещение** — сколько закладывать.
4. **Что делать там** — помечено «(сгенерированная идея)», потому что это не факт из данных.
5. **Источник** каждого места — ссылка на объект OpenStreetMap (и Wikidata, если описание оттуда).
6. **Честные часы**: «открыто» только если часы OSM это подтверждают на текущее время, иначе —
   «часы работы неизвестны — уточните перед выходом».
7. **Использованные данные названы**: локация и откуда она (браузер или слова пользователя),
   фильтры и категории.
8. Если локации нет — система **спрашивает**, а не угадывает.

Скрипт дополнительно проверяет: каждое выбранное место есть в результатах инструментов, его
название и ссылка на источник есть в тексте, у каждого места ровно одна строка «Что делать» с
пометкой, ночью рекомендуются только места с подтверждённым статусом «открыто», в режиме
«на коляске» — только места с `wheelchair=yes`, маршрут укладывается в бюджет.

«Совпадает с запросом» в строке «Почему» пишется только тогда, когда интерес подтверждён данными
места (категория, теги OSM). Пожелания, которых в данных нет (розетки, тишина, цены), не
засчитываются как совпадение — для них отдельная строка «данных нет».

В разделах ниже ответы сокращены до строк о местах; полный текст — в JSON. Координаты в
сценариях 3–6, 8 и 10 — тестовые, переданные в поле `location` так же, как их передаёт кнопка
геолокации браузера (уже округлёнными).

## 1. Экспо 2017 — пример из кейса

**Вход:** «Я у здания Экспо 2017, хочу что-то необычное на 1–2 часа, пешком.» Локация — из текста.

**Ожидаемый тип ответа:** 1–3 необычных места рядом с Экспо с расстоянием, «почему», временем и
планом; часы и источник у каждого.

**Фактический ответ** (live):

```text
Локация: Alem.ai (бывший Нур Алем), территория ЭКСПО (из ваших слов).
Фильтры: До 30 мин пешком до каждого места; До 40 мин пешком — для мест с описанием в Wikidata,
фото или оценкой популярности; Вся прогулка — до 120 мин; Категории: достопримечательность, …

1. 25-ти летие Независимости — 507 м, 9 мин пешком (оценка).
Почему: достопримечательность — совпадает с запросом «необычное», 9 мин пешком, ближе всех из предложенных.
На посещение: 30 мин (оценка).
Что делать: осмотреть достопримечательность и сделать короткую остановку (сгенерированная идея).
Часы: часы работы неизвестны — уточните перед выходом.
Источник места: OpenStreetMap (way/1460763574).

2. Ботанический сад — 1909 м, 34 мин пешком (оценка). Почему: парк рядом — для прогулки, не
   достопримечательность, описание Wikidata: «Достойный парк в Астане».
3. Триумфальная арка Мангилик Ел — 1965 м, 35 мин пешком (оценка). Почему: ещё достопримечательность
   по запросу «необычное», описание Wikidata: «Монумент в Астане».
```

В mock: 25-ти летие Независимости, Триумфальная арка Мангилик Ел, Аллея мира и согласия (539 м,
парк) и предупреждение «Поблизости в данных мало музеев, галерей и арт-объектов…».

**Соответствие:** 3 места — да; расстояние и минуты — да; почему — да; время — да; что делать с
пометкой — да; источник — да; честные часы — да (у всех трёх «неизвестны»); локация и фильтры
названы — да.

**Замечания:** сам «Нур Алем» исключён как точка старта. Музея будущего искусства и террасы
отеля из примера организаторов в данных OSM нет. Для заметных мест (описание Wikidata, фото,
популярность) радиус расширен до 40 мин — так в ответ попала Триумфальная арка. В live
предупреждение о нехватке музеев не выведено, хотя одно из трёх мест — парк. Описание
Ботанического сада из Wikidata («Достойный парк в Астане») показано как есть.

## 2. Mega Silk Way, прогулка 30–60 минут

**Вход:** «Я сейчас возле Mega Silk Way, хочу прогуляться 30–60 минут — что посоветуете?»
Локация — из текста.

**Ожидаемый тип ответа:** 1–3 места для короткой прогулки, укладывающиеся в 60 минут.

**Фактический ответ** (mock и live одинаковы):

```text
Локация: Mega Silk Way (из ваших слов).
Фильтры: До 15 мин пешком до каждого места; Вся прогулка — до 60 мин; Категории: памятник, …, парк, сад, кафе.

На посещение: 30 мин (оценка).
Что делать: выпить кофе и отдохнуть перед следующей остановкой (сгенерированная идея).
Часы: открыто до 23:00 по данным OpenStreetMap.

2. NU Park — 562 м, 10 мин пешком (оценка).
```

**Соответствие:** 2 места — да; все пункты чек-листа — да. Часы у кафе взяты из OSM и проверены

**Замечания:** в прогулку без явного интереса допускается не больше одного кафе. Самый медленный
живой ответ прогона — 26 с.

## 3. Тихое место с кофе и розеткой

**Вход:** «Хочу тихое место с кофе и розеткой недалеко от меня.» Локация — браузер,
51.089, 71.416 (район ЭКСПО).

**Ожидаемый тип ответа:** 1–3 кафе рядом; честно — что про розетки и тишину известно.

**Фактический ответ** (live):

```text
Локация: 51.089, 71.416 (геолокация браузера).
Фильтры: До 15 мин пешком до каждого места; Категории: кафе, библиотека; Тихо: шум не проверен.
Учёл: тихо. Уровня шума в данных нет — тишину проверить не могу.

1. Лепим и варим — 570 м, 10 мин пешком (оценка).
Почему: кафе — совпадает с запросом «кофе», открыто до 23:00, 10 мин пешком.
На посещение: 30 мин (оценка).
Розетки: данных нет — уточните перед выходом.
Уровень шума не проверен — уточните у места.
Что делать: выпить кофе и отдохнуть перед следующей остановкой (сгенерированная идея).
Часы: открыто до 23:00 по данным OpenStreetMap.

2. Gasteria — 465 м, 9 мин пешком (оценка). Открыто до 23:00.
3. Starbucks — 495 м, 9 мин пешком (оценка). Описание сети из Wikidata; открыто до 22:00.
```

нет, и это сказано у каждого места. Совпадение с запросом засчитано только по «кофе».

**Замечания:** в live первым стоит более дальнее место (570 м раньше 465 м) — порядок по
релевантности, в ответе это не пояснено.

## 6. Ночная активность

## 8. На коляске: кафе до 10 минут

**Вход:** «Передвигаюсь на коляске, найди кафе в пределах 10 минут пешком.» Локация — браузер,
51.128, 71.43.

**Ожидаемый тип ответа:** только места с подтверждённой доступностью; если таких нет — честно
сказать.

**Фактический ответ** (mock и live одинаковы):

```text
Фильтры: До 10 мин пешком до каждого места; Категории: кафе, библиотека; Только места с подтверждённой доступностью для колясок.
Подходящих мест с этими условиями не найдено. Попробуйте изменить фильтры.
```

**Соответствие:** фильтр назван — да; место без подтверждения не выдано за доступное — да.

**Замечания:** `wheelchair=yes` есть только у 42 из 1250 мест. Маршрутизация для коляски не
поддерживается: в пешеходной сети разрешены ступени.


**Соответствие:** честный пустой ответ — да.

**Замечания:** «музей» в запросе превращается в фильтр «музей, галерея», а сам Нур Алем исключён
как точка старта. Ответ мог бы предложить расширить фильтр до достопримечательностей

## 12. Уточнение во втором сообщении: «мало денег»

**Вход:** первое сообщение «Ищу кофе возле Байтерека», затем — с полной историей (оба сообщения
пользователя и ответ помощника между ними) — «У меня мало денег». Локация — из текста.

**Ожидаемый тип ответа:** уточнение учтено и названо; про цены — честно, раз в данных их нет.

**Первый ответ** (live): CrepeCafe (182 м, открыто до 00:00), Degirmen (240 м, открыто до 00:00),
Национальная академическая библиотека (217 м, часы неизвестны).

**Фактический ответ на уточнение** (live):

```text
Локация: Байтерек (из ваших слов).
Фильтры: До 15 мин пешком до каждого места; Категории: кафе, библиотека; Бюджет: цены не проверены.
Учёл: мало денег. Цен в данных OpenStreetMap нет — проверить стоимость не могу; цены уточните по
ссылке «Открыть в 2ГИС».

1. CrepeCafe — 182 м, 4 мин пешком (оценка).
Почему: кафе — совпадает с запросом «кофе», открыто до 00:00, 4 мин пешком, ближе всех из предложенных.
2. Degirmen — 240 м, 5 мин пешком (оценка). Открыто до 00:00.
3. Национальная академическая библиотека Республики Казахстан — 217 м, 4 мин пешком (оценка).
   Почему: библиотека, 4 мин пешком. Часы: часы работы неизвестны — уточните перед выходом.
```

В mock первый ответ — CrepeCafe, Degirmen, Лепим и варим (318 м); ответ на уточнение — с той же
строкой «Учёл: мало денег…», третье место заменено библиотекой.

**Соответствие:** уточнение понято и названо в фильтрах — да; цены не выдуманы — да; локация из
первого сообщения сохранена — да; остальные пункты чек-листа — да.

**Замечания:** цен в OSM нет, поэтому набор мест после уточнения почти не меняется — система
говорит об этом прямо, а не переставляет кафе «как будто дешевле». Так же обрабатываются «поближе»
(меньше радиус, места от ближнего) и «открыто сейчас» (только места со статусом «открыто») —
это покрыто модульными тестами, по HTTP в этом прогоне не проверялось. Категория «кафе»
включает библиотеки как тихое место, поэтому на запрос про кофе третьим попадает библиотека — без
пометки «совпадает с запросом».

Гостиницы и посуточная аренда исключены при сборе (131 объект), дубликаты удалены (62).
Связь с Wikidata есть у 23 мест, описания — у 47, фото с проверенной свободной лицензией — у 15.
Заметные места (описание Wikidata, фото, популярность) ранжируются выше и допускаются чуть дальше

## Этика и приватность

- **Геолокация — только по кнопке** «Использовать мою геолокацию». Без нажатия браузер координаты
  не передаёт; можно просто написать ориентир.
- **Округление до ~100 м** (3 знака после запятой) — дважды: в браузере и на сервере при проверке
  запроса, до того как координаты увидит модель.
- **Ничего не хранится**: нет базы данных, аккаунтов и истории. Координаты и тексты запросов не
  кэшируются и не логируются; в лог API пишется только категория ошибки. История диалога живёт
  только в браузере и отправляется вместе с новым сообщением.
- **Провайдер модели видит текст запроса** в режиме live (OpenAI Responses и эмбеддинги). В
  режиме mock данные не покидают сервер. Пеший маршрут считается локально, координаты
  маршрутизатору не отправляются.
- **Источники помечены**: у каждого места — ссылка на объект OpenStreetMap; описания из Wikidata
  подписаны «(Wikidata)».
- **Сгенерированное помечено**: каждая строка «Что делать» заканчивается «(сгенерированная
  идея)»; расстояния, время и длительность посещения — «(оценка)».
- **Нет уверенного «открыто»** без данных: статус «открыто» только по часам OSM на текущее время.
- **Лицензии**: © участники OpenStreetMap (ODbL), Wikidata (CC0), фото Wikimedia Commons с автором
  и лицензией у каждого изображения. Сервисы, запрещающие парсинг (Google Maps, 2GIS, Яндекс), не
  используются для сбора данных; ссылка «Открыть в 2ГИС» в карточке только ведёт на их сайт.

## Ограничения

- **Свежесть OSM**: снимок 19.10.2026. Закрывшиеся и новые места, сменившиеся часы не отражаются
  до повторного `pnpm collect`.
- **Покрытие**: часы работы — 25,8 % мест, описания — 3,8 %, Wikidata — 1,8 %, фото — 1,2 %
  (15 мест), доступность для колясок — 42 места. Это выборка в прямоугольнике Астаны, не полный
  реестр.
- **Расстояния в поиске — оценка**: прямая с поправкой на улицы. Точный путь считается только в
  маршруте.
- **Пешеходная сеть** (134 017 узлов, 309 938 рёбер, 862 несвязанных компонента): входы в здания,
  лестницы и временные перекрытия не проверены; ступени допускаются, поэтому маршрут не годится
  для коляски. Если точки не соединены, линия не рисуется и это сообщается.
- **Нет данных** о погоде, событиях, ценах, загруженности, дороге до аэропорта. Уточнения про
  бюджет учитываются только честной оговоркой, а не фильтром.
- **Сомнительные категории и описания** OSM и Wikidata попадают в ответ как есть (например,
  «Астана-Экспо КС» отмечена в OSM как галерея; описание Ботанического сада — «Достойный парк в
  Астане»).
- **Модель может ошибиться в выборе инструмента**; формат ответа и проверки фактов от этого
  защищены, потому что текст собирает код. В прогоне модель 1 раз пропустила необязательный поиск
  перед маршрутом.
- **Задержка live**: в этом прогоне медиана около 16 с, максимум 26 с. Эмбеддинг запроса имеет
  таймаут 8 с; в этом прогоне поиск ни разу не откатился на лексический (в одном из прошлых — в
  нескольких сценариях; об этом сказано в ответе).
- **Один город и один язык ответа** — русский.

## Как воспроизвести

```bash
pnpm install
pnpm build
# mock: без ключа и сети
LLM_PROVIDER=mock pnpm start -p 3201
pnpm scenarios http://127.0.0.1:3201 mock
# live: нужен LLM_API_KEY в .env
LLM_PROVIDER=responses pnpm start -p 3202
pnpm scenarios http://127.0.0.1:3202 live
# PDF этого документа (нужен установленный Chrome)
pnpm scenarios:pdf
```

PowerShell: `$env:LLM_PROVIDER='mock'; pnpm start -p 3201`. Скрипт `pnpm scenarios` записывает
результат прогона в `docs/presentation-http-probes.json` (раздел `runs.mock` или `runs.live`) и
завершается с ошибкой, если хоть один сценарий нарушил проверки. Сценарий 12 (два сообщения)
записан там же в разделе `runs.followup`. Результаты зависят от текущего времени: статус часов
вычисляется на момент запроса по Астане.

Пересборка данных: `pnpm collect` (места), `pnpm embed` (векторы, нужен ключ).
