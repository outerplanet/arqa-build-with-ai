# Сценарий демо-видео (2–3 минуты)

Для того, кто записывает. Видео загружается на YouTube с доступом **«по ссылке»**; ссылку проверить
из окна инкогнито и отдать Оразу до 23:00.

## Подготовка (10 минут)

```bash
git pull
pnpm install
cp .env.example .env        # PowerShell: Copy-Item .env.example .env
pnpm dev                    # http://localhost:3000
```

- Без ключа работает режим `mock`: те же инструменты и те же тексты ответов, но в шапке будет
  плашка «Демонстрационный режим». Это честно и допустимо.
- С живой моделью: в `.env` поставить `LLM_PROVIDER=responses`, `LLM_MODEL=gpt-6-luna`
  и `LLM_API_KEY` (ключ передаётся лично, не через чат). Ответ идёт 10–25 секунд — паузу
  можно вырезать при монтаже.
- Окно браузера 1440×900, масштаб 100%, светлая тема. Закрыть лишние вкладки и уведомления.
- Запись: OBS или встроенная запись экрана Windows (Win+Alt+R). Голос — на русском.

## Чего не делать

- Не показывать `.env` и ключ в кадре.
- Не говорить того, чего нет: «открыто сейчас» без подтверждения, отзывы, цены, события.
- Если ответ получился неудачным — перезапросить; монтажом можно вырезать ожидание, но не
  подменять ответы.
