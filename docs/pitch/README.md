# Питч-презентация

Отдельная дизайнерская версия. Технические `docs/presentation.md` и `docs/presentation.pdf`
не заменены. Основной питч: слайды 1–10, целевой тайминг **6:15**. Слайды 11–13 — для вопросов.
Живой прогон с таймером обязателен: указанный тайминг является планом, а не измерением выступления.

## Что открыть

- `output/pitch/astana-pitch.pdf` — готовый PDF 16:9, 13 слайдов.
- `output/pitch/astana-pitch.html` — автономный показ в браузере. Стрелки переключают слайды,
  `F` включает полный экран, `N` показывает подробные заметки. Интернет для просмотра не нужен.
- `docs/pitch/speaker-notes.md` — полная речь, тайминг каждого слайда и источники.
- `docs/pitch/deck.json` — редактируемый текст презентации.
- `docs/pitch/astana-pitch.pdf` — идентичная копия PDF рядом с исходниками.

## Дизайн и факты

Вечерняя Астана, глубокий синий фон, бирюзовый и тёплый золотой акценты, чередование
тёмных и светлых композиций. Заголовки и числа крупные, диаграммы строятся по данным,
основные детали рассказа вынесены в заметки. Текст PDF выделяется и копируется.

Фон `assets/astana-night-ai.png` создан Imagegen специально для презентации.
Это художественная AI-иллюстрация, не фотография и не географическая карта.
Нативные диаграммы категорий и времени отражают реальные числа.

Источник чисел: `data/collect_summary.json`, `data/walking-summary.json` и
`docs/pitch/runtime-check.json`. После pull до `8671a29` заново проверены ответы Экспо
и маршрута через mock. Сейчас 1250 POI, 323 графика, 67 описаний (включая 45 описаний сетей),
маршрут на 68 минут по графу и ответ у Экспо 507 м / 9 минут. Векторы OpenAI: 1250 × 256,
SHA-256 соответствует данным. Mock использует лексику; семантический запрос требует ключа OpenAI.
Проценты и ограничения раскрыты в заметках. Не заявлены пользовательские
метрики, выручка, подтверждённый городской пилот или работа на всех ОС.

## Пересборка

```bash
python3 -m venv .venv-pitch
.venv-pitch/bin/python -m pip install -r scripts/pitch-requirements.txt
.venv-pitch/bin/python scripts/build_pitch.py
```

Для Windows: `py -3 -m venv .venv-pitch`, затем команды через
`.venv-pitch\Scripts\python.exe`. Нужен Arial или DejaVu Sans, как у основного PDF-экспортера;
нестандартный путь задаётся через `ASTANA_PDF_FONT_DIR`. Шрифты не скачиваются из CDN.

Сборщик проверяет размещение текста и намеренно прекращает работу при изменении
контрольного количества POI или маршрута: перед новым экспортом необходимо сверить рассказ
с обновлённым протоколом. `output/pitch/layout-check.json` хранит координаты текста для QA.

## Как выступать

Начать с ситуации «есть 90 минут», затем показать запрос и проверенный результат.
На слайде с данными объяснить автоматический сбор. На RAG-слайде назвать цепочку обработки,
не читать весь технический стек. У маршрута вслух сказать, что расстояния приблизительные.
У приватности разделить поведение приложения и передачу данных живому провайдеру.
Закончить предложением пилота, а не обещанием уже измеренного эффекта.

На вопросы про полноту, платформы и пешеходный граф перейти к слайдам 11–13.
Если показывается приложение, честно назвать `mock` и лексический режим без API-ключа.
Публичность GitHub, публикацию видео и отправку формы проверить отдельно по
`docs/submission-status.md`.
